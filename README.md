# libre
Электронная библиотека
Название: Электронная библиотека (Library Manager)

Язык и технологии: Python 3, Tkinter (графический интерфейс), JSON (хранение данных), Pillow (работа с изображениями), стандартные библиотеки os, subprocess.

Назначение: Программа для учёта книг в личной или домашней библиотеке. Позволяет хранить информацию о книгах (название, автор, год, жанр), добавлять файлы книг (в первую очередь текстовые форматы) и обложки, просматривать их в удобном табличном виде, искать, сортировать, открывать текстовые файлы для чтения.

Основные функции:

Управление книгами: добавление, удаление, редактирование (через удаление + добавление), обновление списка.

Поиск и сортировка: поиск по названию и автору, сортировка таблицы по любому столбцу (ID, название, автор, год, жанр) с возможностью обратного порядка.

Хранение данных: все записи сохраняются в JSON-файл library.json. При запуске данные загружаются из него.

Обложки: возможность прикреплять к книге изображение обложки (PNG, JPG, JPEG, GIF). Обложка отображается в правой панели при выборе книги.

Чтение книг: для текстовых файлов (.txt) при двойном клике открывается новое окно с текстом и полосой прокрутки. Другие форматы (PDF, DOCX и пр.) открываются стандартной системной программой, ассоциированной с расширением.

Интерфейс: оконное приложение с разделением на две панели: слева — таблица книг и поиск/кнопки, справа — область просмотра обложки и подробной информации о выбранной книге.

Кастомизация внешнего вида: тёмно-коричневая цветовая гамма («библиотечный стиль»), настраиваемый фон, цвет кнопок и таблицы.

Структура данных (книга):

id — уникальный целочисленный идентификатор,

title — название книги,

author — автор,

year — год издания (целое число или пустое),

genre — жанр,

file_path — путь к файлу книги,

cover_path — путь к файлу обложки (необязательно).
